# Atlas Studio 使用说明（给朋友）

## 一句话版本

解压 → 双击 `app\启动 Atlas Studio.bat` → 浏览器自动打开。

---

## 前置条件

| 需要 | 说明 |
|---|---|
| **ComfyUI** | 必须已装好并在运行（就是平时生成图的那个）。程序会自动找它。 |
| **Python** | 用 ComfyUI 自带的那个就行，不用单独装。程序会自动找。 |
| **素材库** | `data/pose-atlas`（288 个姿态）和 `data/costume-gallery`（1407 套服装），随包一起发。 |

**不需要**改任何配置文件。

---

## 如果自动找不到 ComfyUI

程序会提示 "ComfyUI was not found"，这时设一个环境变量指一下位置就行
（PowerShell 或 CMD 里执行一次，然后重新双击 BAT）：

```powershell
set ATLAS_COMFY_ROOT=D:\ComfyUI_windows_portable
```

`D:\ComfyUI_windows_portable` 换成你实际的 ComfyUI 目录 ——
就是**同时包含 `ComfyUI` 文件夹和 `python_embeded` 文件夹**的那一层。

想永久设置：

```powershell
setx ATLAS_COMFY_ROOT "D:\ComfyUI_windows_portable"
```

---

## 打开后

- 页面右上角有 **🔗 访问地址** 按钮，点开能看到所有可用地址，一键复制
- 同一个局域网里，别的设备可以用面板里的「局域网地址」打开
  （需要把 `app/config.json` 里的 `host` 改成 `0.0.0.0` 再重启）

## 常见问题

**Q: 双击后闪退 / 提示找不到 Python**
A: 设 `ATLAS_PYTHON` 环境变量指向 ComfyUI 的 python：
```powershell
set ATLAS_PYTHON=D:\ComfyUI_windows_portable\python_embeded\python.exe
```

**Q: 提示 ComfyUI 未响应**
A: ComfyUI 没启动。先开 ComfyUI，再开 Atlas Studio。

**Q: 端口被占用**
A: 改 `app/config.json` 里的 `port`（比如改成 8200），重启即可。
页面会自动跟随，不用改别的地方。

**Q: 素材库显示 0 个**
A: 确认 `data` 文件夹和 `app` 是同级的（解压时别弄散层级）。
正确结构：
```
Atlas-Studio\
  app\      ← 双击里面的 BAT
  data\     ← 素材库
  skill\    ← 生成逻辑
```

---

## 别关窗口

Atlas Studio 的服务跑在 BAT 弹出的那个黑色窗口里，**关掉窗口 = 关掉服务**。
想让它后台常驻，单独开个窗口跑就行。
