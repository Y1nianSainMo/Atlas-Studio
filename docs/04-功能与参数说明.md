# 04 · 功能与参数说明

界面分左右两栏：左边是**投放位 + 参数**，右边是**素材库**。

---

## 一、三个投放位（左侧）

| 位 | 拖什么 | 说明 |
|---|---|---|
| **01 · 姿势** | 姿态库里的线稿人台，或自己的姿势图 | 只取姿势与机位，不取人台的胖瘦和画风 |
| **02 · 服装** | 衣装库里的一套，或自己的服装图 | 取整身服装 + 鞋包配饰 + 袜子 |
| **03 · 人脸**（可选） | 一张真人照 | 锁定长相。**不给容易生成白模人台**，强烈建议放 |

- 从右侧库拖过来即可；也可以点投放位从本地选图
- 放好姿势后，槽位里会出现**机位按钮**（正面/俯视/仰视/侧面/斜侧），点一下立刻换图
- 点右上角的 ✕ 清空

---

## 二、姿态控制（4 档）

| 档 | 参考图 | 适合 | 耗时 |
|---|---|---|---|
| **骨架（默认）** | 骨架 + 线稿 + 服装 | 大动作、复杂手脚（抱膝、单腿后抬、抬腿过肩） | ~57s |
| 线稿 + 深度 | 深度 + 线稿 + 服装 | 常规站坐姿 | ~52s |
| 仅深度 | 深度 + 服装 | 求快，姿势简单 | ~45s |
| 仅线稿 | 线稿 + 服装 | 最快 | ~40s |

> **骨架**是把人台用 SDPose 提成「点+棍」的关节图再喂给模型，比线稿/深度都硬。
> 同一个姿势的骨架只算一次（缓存），之后不再多花时间。

---

## 三、面孔（5 档）

`中国（默认）` / `韩国` / `日本` / `美国` / `混血`

- 不指定时模型会往欧美脸漂，所以默认固定成中国
- **一旦放了 03 位人脸照，这套族裔描述会被跳过**，完全以照片为准

---

## 四、身材（7 档）

| 档 | 体型 |
|---|---|
| 超瘦 · 纸片人 | 几乎无脂肪、无曲线 |
| **极瘦 · 骨感（默认）** | 腰细腿细、锁骨明显 |
| 纤细 · 网红 | 苗条 |
| 模特 · 高瘦长腿 | 高挑纤细 |
| 标准 · 匀称 | 偏瘦的匀称 |
| 丰满 · 沙漏曲线 | 有曲线但腰细 |
| 丰腴 · 偏胖 | 圆润 |

**注意**：这一档不只是文字描述，还会**把参考图横向压窄**（压多少见下），所以效果比纯提示词强得多。

---

## 五、胖瘦微调（滑块 70% ~ 108%）

控制「参考图横向压缩比」——数字越小人越瘦。

| 滑块 | 效果 |
|---|---|
| 72% | 极瘦（四肢会偏细长，再低比例会失真） |
| 84% | 默认，瘦但自然 |
| 95% | 明显丰满 |
| 105% | 偏胖 |

切「身材」档位时滑块会自动跳到该档默认值，手动拖则覆盖档位。
**78~84% 是自然度与瘦度最平衡的区间。**

---

## 六、身高（4 档）

`娇小 155` / `标准 163（默认）` / `高挑 170` / `超模 178`

影响整体高挑感与四肢长度（走提示词）。

---

## 七、腿身比（4 档）★真变形

| 档 | 拉伸倍数 |
|---|---|
| 短腿 | 腰线以下 ×0.90 |
| 标准 | ×1.00 |
| 长腿 | ×1.12 |
| **超长腿** | ×1.24 |

实现方式：把参考图从腰线（0.52H）切开，下半身纵向拉伸，再整体缩回原画幅高度。
效果就是「同画幅里人站得更高、头略小」的九头身感。**这是改图不改词，所以很硬。**

---

## 八、三围（3 个滑块，0~100，右大）

| 滑块 | 小 → 大 |
|---|---|
| 胸 | 平胸 → 很丰满 |
| 腰 | 粗腰 → 极细腰（注意：右边是**细**） |
| 臀 | 窄臀直胯 → 很宽的胯与曲线 |

走提示词分档描述，配合「身材」档一起用效果最好。

---

## 九、其他参数

| 参数 | 说明 |
|---|---|
| **比例** | 2:3（832×1216）/ 3:4 / 9:16 / 1:1 / 864×1536。竖构图选 2:3 或 9:16 |
| **种子** | 同种子 + 同参数可复现。换一张不想改配置就点「换个种子再来一张」 |
| **换脸精修** | **默认勾选**。勾了会跑第二遍，用换脸 LoRA 把脸精确贴上去（+20~25s） |
| **LoRA 强度** | 默认 0.95。0.88~0.92 皮肤更自然，1.0 以上脸更贴但可能发糊 |
| **步数** | 默认 10。**低于 8 容易出现三条腿/畸形手**；12 更稳但更慢 |
| **描述框** | 可补场景/光线/氛围，会拼在提示词最前面，权重最高 |

## 十、生成结果

- 完成后结果区显示 **成品**（换脸后），若跑了换脸还会多一张 **底图**
- 状态栏会明确写「**已换脸**」或失败原因（未勾选换脸 / 没有人脸照 / 未找到头部 / 换脸报错）
- 可展开「运行日志」看每一步耗时
- 图片按日期存放在 `app/work/outputs/<日期>/时-分-秒_成品.jpg`

---

## 十一、右侧素材库

- **姿态库** 288 组，5 个机位，共 1439 张线稿人台（灰底，800×1200）
- **衣装库** 1407 套，三档分辨率，可按季节（春/夏/秋/冬/水着/ランジェリー…）筛选
- 支持搜索：中文姿势名、英文服装关键词、编号（如 `P019`、`SPR-0001`）
- 点卡片开大图：可切机位、可直接「用作姿势参考 / 服装参考」

---

## 十二、性能参考（12G 显卡）

| 场景 | 耗时 |
|---|---|
| 仅线稿，无换脸 | ~40s |
| 骨架模式，无换脸 | ~57s |
| 骨架 + 换脸 | ~80s |
| 换新姿势首次（要算骨架+深度） | 再 +12~15s |

同一姿势、同一腿身比再次生成时缓存命中，不再额外耗时。
