# 03 · 部署与迁移

## 一、首次部署（新机器）

### 1. 准备 ComfyUI

按 `docs/01` 装 3 个节点包，按 `docs/02` 放好模型。启动后确认：

```
http://127.0.0.1:8188/system_stats   能返回 JSON 即可
```

### 2. 放好本项目

整个 `Atlas-Studio-2026-10-30` 文件夹放在任意位置（路径最好不要有中文和空格）。

### 3. 改 2 个路径

**① `app/启动 Atlas Studio.bat` 第 6 行** —— 指向你的 ComfyUI 内置 Python：

```bat
set PY=E:\ComfyUI_Mie_V33\python_embeded\python.exe
```

**② `skill/flux2-klein-portrait/config.json`** —— 三处：

```json
"api": "http://127.0.0.1:8188",
"comfy_root": "E:/ComfyUI_Mie_V33/ComfyUI",
"python": "E:/ComfyUI_Mie_V33/python_embeded/python.exe"
```

### 4. 双击启动

`app\启动 Atlas Studio.bat` → 自动开浏览器。

---

## 二、目录内路径已经是相对的了

`app/config.json` 用的是相对路径，**只要保持包内目录结构不变，整包搬到任何盘都不用改**：

```json
"skill_dir":    "../skill/flux2-klein-portrait",
"pose_dir":     "../data/pose-atlas",
"costume_dir":  "../data/costume-gallery"
```

`studio_server.py` 里用 `_abs()` 把相对路径按 config 所在目录解析，所以从任何工作目录启动都对。

---

## 三、迁移时还要注意

| 项 | 说明 |
|---|---|
| `app/work/` | 输出和缓存目录，**可以不搬**（会自动重建）。想保留历史出图就一起拷 |
| `app/work/depth`、`work/pose` | 深度图/骨架图缓存，删了会自动重算（每个姿势首次 +12s） |
| `data/pose-atlas`、`data/costume-gallery` | 素材库，必须搬。带 `.git`，想省空间可以删 `.git`（不影响运行） |
| `versions/2026-10-29-v1` | 上一稳定版备份，可随时回滚 |

## 四、回滚到旧版

```bat
copy /Y app\..\versions\2026-10-29-v1\studio_server.py app\
copy /Y app\..\versions\2026-10-29-v1\index.html      app\
copy /Y app\..\versions\2026-10-29-v1\config.json     app\
rem 注意：旧版 config 是绝对路径，要按新位置改一遍
```

## 五、排错

| 报错 | 原因 | 处理 |
|---|---|---|
| bat 闪一下就没了 | Python 路径不对 | 改 `set PY=` 那行 |
| 页面「检测中」不动 | 服务没起来 | 看 Atlas Server 窗口 |
| `ComfyUI 未启动` | 8188 没响应 | 单独启动 ComfyUI |
| `Cannot find module comfy` | skill 路径不对 | 查 `config.json` 的 `skill_dir` |
| `KSampler ... Fault failed: 2` | 显存不足 | 程序会自动清显存重试 2 次；仍失败就降 `steps` 或关别的程序 |
| 生成出白模/线稿人台 | 没放人脸照 | 03 位放一张真人脸 |
| 换脸没生效 | 没勾「换脸精修」 | 默认已勾，检查是否手动取消 |
| 丝袜/袜子消失 | 服装关键词没解析到 | 用库内服装；自定义图会走条件式兜底 |
