# 01 · 依赖与节点清单

本项目的生成链路是「多图参考 + 指令编辑」，**不是传统 ControlNet**。
下面三个节点包是**必须**的，缺一个就跑不起来。

---

## 一、必需节点（3 个）

### 1. Comfyui-PainterFluxImageEdit ★核心

- **作用**：整个生成的心脏。`PainterFluxImageEdit` 节点接受 1~4 张参考图 + 一段文字指令，
  一次前向同时做「姿势还原 + 服装替换 + 人脸参考」。所有姿势/衣装/骨架/深度图都是喂给它的 `Picture N`。
- **用到的节点**：`PainterFluxImageEdit`
- **输入**：`clip` / `vae` / `prompt` / `mode`（`1_image` … `4_image`）/ `image1..4` / `width` / `height`
- **输出**：`(positive, negative, latent)` 三路 —— **latent 必须显式取索引 2**，取错会直接 400 报错。

### 2. comfyui_controlnet_aux

- **作用**：提供深度图预处理器。
- **用到的节点**：`DepthAnythingV2Preprocessor`（`ckpt_name=depth_anything_v2_vitl.pth`，`resolution=1024`）
- **用途**：把线稿人台/压瘦后的参考图转成灰度体积图，作为「线稿+深度」模式或纯深度模式的一路参考。

### 3. ComfyUI-SDPose-OOD-master ★姿态精度关键

- **作用**：从线稿人台提取**全身骨架**（含双手十指、双脚脚趾），输出标准 OpenPose 风格的「点+棍」图。
- **用到的节点**：
  - `SDPoseOODLoader` → `model_type=WholeBody`、`unet_precision=fp16`、`unload_on_finish=True`
  - `SDPoseOODProcessor` → `score_threshold=0.3`、`overlay_alpha=1.0`、`keep_hand/feet/face=True`
- **注意**：
  - `unload_on_finish` 一定要 `True`，否则 SDPose 常驻显存，12G 卡跑 flux 时会 OOM。
  - **不要用 `SDPoseDrawKeypointsV2` 绘制**：WholeBody 关键点数与它期望的形状不一致，会报
    `cannot reshape array of size 204 into shape (70,3)`。直接取 `SDPoseOODProcessor` 的第 1 路 IMAGE 输出即可。
  - 传统 `DWPose` / `OpenposePreprocessor` 对线稿人台**无效**（输出纯黑），不要走那条路。

## 二、可选节点（Qwen 硬约束路线，当前未启用）

如果以后要用**真正的 ControlNet 硬约束**（姿态精确到手指朝向），需要换整套生成链路：

| 节点包 | 用途 |
|---|---|
| ComfyUI-GGUF | 加载 `qwen-image-2512-Q4_K_S.gguf` |
| 内置 `ControlNetLoader` + `ControlNetApplyAdvanced` | 加载 InstantX ControlNet Union |
| `QwenImageDiffsynthControlnet`（备选） | DiffSynth 系 patch |

控制模式由 `SetShakkerLabsUnionControlNetType` 或模型自带 `control_mode` 切换：
`canny` / `soft edge` / `depth` / `openpose`，官方建议强度 **0.6~0.8**、结束时间 **0.8**。

> 代价：换模型 = 换脸 LoRA 要重找、服装一致性要重新验证、整套节点图重写。
> 现有 flux 链路已验证稳定，非必要不建议切。

## 四、四档姿态控制分别用到什么

| 模式 | 参考图构成 | 耗时（832×1216 / 10 步） |
|---|---|---|
| **骨架**（默认，最准） | 骨架 + 线稿 + 服装 | 约 57s（骨架首次 +12s） |
| 线稿 + 深度 | 深度 + 线稿 + 服装 | 约 52s |
| 仅深度 | 深度 + 服装 | 约 45s |
| 仅线稿 | 线稿 + 服装 | 约 40s |

骨架模式比「线稿+深度」多认关节坐标，**抱膝、单腿后抬这类大动作只有骨架模式能准确还原**。

---

## 五、换脸链路（不需要额外节点）

- 用 `LoraLoaderModelOnly` + `klein9b_smart_character_swap.safetensors`（触发词 `jhuangswap`）
- 遮罩由本地 Python 生成（背景差分 + Haar 找头部 + 椭圆羽化），**不用 ComfyUI 的人脸检测节点**
- 关键点：只在图像顶部 55% 找脸并做合理性校验，否则 Haar 会误检到腿，导致「换脸等于没跑」
